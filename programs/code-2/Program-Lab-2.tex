\Practicum{Feed Filtering for Financial Fortunes}{%
Prof. Fit works for the investment firm Dewey Robem \& Cheetum.
The firm uses a series of scripts to programmatically download, parse and analyze these sources in real time to inform their automated trading algorithms.
Prof. Fit has been tasked with extending the research capabilities of a keyword research script written by a former employee name Mac Jaw who disappeared mysterously.
Mac Jaw's script filters an RSS feed for articles containing a keyword.
The firm needs you to extend the script to find any webpages linked to by the articles which \textit{also} contain the keyword.
}
%
\Practicum{Instructions}{%
Complete the \texttt{news-scanner.py} script in order to automate the collection and analysis of news articles.
In this programming assignment we will learn the basics of networked automation and response parsing of through HTTP requests.
The tool we will be using is \texttt{requests} to download the content of URLs, as well as \texttt{BeautifulSoup} to parse webpage content.\\[5mm]%
Complete the \textit{eight tasks} within the provided \texttt{news-scanner.py} script.
